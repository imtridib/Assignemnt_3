# Web Development Assignment 03

A front-end assignment repository containing the implementation and the original design/reference resources for a responsive web page.

## Project files

The repository contains the page markup and styling alongside design/reference assets. Keep the existing asset and source paths intact when opening or editing the project.

## Run locally

1. Clone or download the repository.
2. Open the main index.html file in a browser, or use VS Code Live Server.
3. Compare the page with the design reference linked below.
